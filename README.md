# 2048

The sliding tile puzzle. Combine matching numbers until a tile reaches 2048.

## Features

- Arrow keys, WASD and swipe controls
- Merging, scoring and best score saved in local storage
- Win overlay at 2048 with an option to keep playing
- Game over detection when no moves remain
- Colour coded tiles up to 8192
- A How to play popup explains the rules

## Running it

Open `index.html` in a browser. There is no build step and no dependencies to install.

## Files

```
index.html   markup
styles.css   styling
script.js    behaviour
```

## Tech

Plain HTML, CSS and JavaScript.
